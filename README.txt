MAVERO FRONT-END STORE

Run locally:
1. Extract the ZIP.
2. Open index.html in a modern browser, or use VS Code + Live Server.

Included:
- Responsive Home, Shop, About and Contact sections
- Product cards, category filters, search and sorting
- Product detail modal
- Working cart: add, remove, quantity changes, subtotal
- Cart persistence with localStorage
- Mobile navigation

Important:
- This is a front-end demo only. No backend, real checkout, payment processing, inventory sync, or email subscription is connected.
- Product names, prices and photos in app.js are demo placeholders. Replace them with your actual products.
- Product photos are loaded from Unsplash and require internet access.
- The supplied MAVERO logo image is included in assets/mavero-logo.jpg.
